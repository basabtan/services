A clear structure around one red point

A website theme taken from the mark: ivory ground, crystal surfaces, graphite lines, and a single ruby for the one thing that matters on each screen.

Get the tokens Read the rules

What the mark dictates

Each trait of the logo becomes one rule. Nothing in the theme comes from anywhere else.

In the markIn the theme
Warm ivory ground, soft floor shadowPage background is ivory. One long, low shadow exists, and only raised items get it.
Clear crystal facetsSurfaces are white and separated by 1px edges, not by fills or shadows.
Graphite latticeAll structure is graphite: text, rules, frames, solid buttons. A 3px rule marks a major division.
One ruby at the crossingRuby appears once per view: the primary action or the key data point.
Hexagon and diamond cutsSquare corners everywhere. Actions get a 10px corner cut. Diamonds serve as markers and data points.
Symmetry on both axesHero and closing statements sit on the center axis. Reference content aligns left on a 4 + 8 grid.
Do
  • Keep ruby under 3% of any screen
  • Separate surfaces with hairlines
  • Use graphite bands to close a page
  • Set headlines in light weight, sentence case
Avoid
  • Two ruby elements competing in one view
  • Rounded corners or pill shapes
  • Ruby as a background behind body text
  • Drop shadows on flat cards

Type

Josefin Sans for display: its pointed A, V and M apexes repeat the cut of the stone. IBM Plex Sans for reading and interface text.

Josefin Sans Light, display

Every edge meets at the same point

IBM Plex Sans Regular, body

Body text runs at 16px on a 1.6 line height and stays under 62 characters per line. Graphite on ivory gives a contrast ratio above 12:1. Numbers use tabular figures in tables and charts so columns align: 1,204.50 and 9,871.25.

Tokens

Paste into any stylesheet. Add data-theme="dark" to the html element for graphite mode.

facet-tokens.css
:root {
  /* palette */
  --ivory: #F3F0EB;      --paper: #FAF8F5;
  --crystal: #FFFFFF;    --facet: #E3E0DB;
  --mist: #C9C6C1;       --steel: #8D8C8A;
  --gunmetal: #55555A;   --graphite: #2C2C2F;
  --onyx: #19191B;
  --ruby: #C2121F;       --ruby-deep: #7C0A12;
  --ruby-glow: #EE2C36;  --ruby-tint: #F5E3E2;

  /* roles */
  --bg: var(--ivory);
  --bg-alt: var(--paper);
  --surface: var(--crystal);
  --surface-sunk: var(--facet);
  --line: #D9D5CF;
  --line-strong: var(--steel);
  --text: var(--graphite);
  --text-muted: #5F5E60;

  --accent-hover: var(--ruby-deep);
  --accent-soft: var(--ruby-tint);
  --on-accent: #FFFFFF;
  --inverse-bg: var(--graphite);
  --inverse-text: var(--ivory);

  /* data */

  --viz-3: var(--mist);

  /* type */
